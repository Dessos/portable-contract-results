# Contributing

Start with one concrete claim about the published profile, corpus or a real modeling dependency. The issue template asks for the source basis and the consequence affected.

Useful reports distinguish:

- source facts and exact locations;
- proposed interpretation;
- confirmations actually supplied by a recognized reviewer, including scope;
- unresolved material inputs;
- observed output differences and why they matter.

Use public material or information you are permitted to disclose. A potential pilot report can describe the workflow and source types without uploading private contracts or personal data.

The frozen v0.1 documents are test objects. A speculative improvement is not a reason to alter them. Report a concern first.

A profile revision requires two genuinely independent implementations to expose a consequence-material semantic disagreement that is not explained by implementation error, non-conformance, input ambiguity or an out-of-scope difference. Record the disagreement before classifying its cause. No public contribution automatically reopens the completed experiments or changes their conclusions.

If proposing a fresh independent study, disclose which prior implementations, results and design discussions you have seen. Isolation and equivalent inputs must be established separately; ordinary public collaboration is not evidence of experiment independence.

For a proposed change, record the previous state, new evidence, proposed change, reason, affected artifacts and whether frozen artifacts would change. Use one of: EDITORIAL, CLARIFICATION, PROFILE REVISION, CONSTITUTIONAL REVISION, SCOPE EXPANSION or NEW INFRASTRUCTURE CLAIM. A category never bypasses the evidence gate.

Prefer existing mechanisms and the smallest sufficient change. A contribution should explain a concrete consequence or application need before suggesting infrastructure.

Public feedback is technical criticism, not presumed contractual authority. No reviewer appointment, external engagement or experiment is made by accepting an issue.

Original documentation contributions are accepted under this repository's CC BY 4.0 license. Identify any third-party material and its applicable terms. Licensing permits derivatives; distinguish modified versions from the canonical frozen v0.1 artifacts.
